# Assignment instructions:
The goal of the project is to design a Bayesian network using AgenaRisk about a topic taken from the
book. Unless you have a strong preference for a topic, we will assign it to you. The network you build
should then be used to analyse different scenarios and give quantitative answers to the questions
detailed below. In the end, you should write a report (4-5 pages + Appendix) detailing the design
choices you made when creating the network and justify them.

AgenarRisk_group7_all_scenarios is the file containing the bayesian network made using the Agena Risk software.
AgenaRisk_project_group7_report.pdf is the file containing the report, which explains the reasoning behind the modelling choices
